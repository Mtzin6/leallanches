# Leal Lanches — versão profissional

A versão inclui visual renovado, hero, categorias, cards de produtos, carrinho, WhatsApp e acesso administrativo por uma mini-logo no rodapé.

### Teste
Abra `index.html` com Live Server no VS Code.

### Importante
O painel desta versão é uma demonstração local usando `localStorage`. Para produção, o próximo passo é conectar Supabase (Auth + banco + Storage), para que alterações feitas no painel sejam refletidas no site público em qualquer aparelho. Não coloque senhas reais no código-fonte.
## V3 — checkout com endereço
- Antes do WhatsApp, o cliente preenche nome, rua, número, bairro e ponto de referência.
- Complemento é opcional.
- O pedido inclui endereço, itens, quantidades, total e pagamento via Pix na mensagem do WhatsApp.
- A identidade visual usa uma marca circular compacta em SVG para evitar distorção da imagem original.
